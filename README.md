# NovaTech Developer Portal

## Description
This repository serves as the central Developer Portal for NovaTech engineering. It provides our technical team with centralized access to infrastructure configurations, API endpoints, internal tools, and setup scripts. This portal is built primarily for onboarding new engineers and streamlining daily development workflows across our engineering teams.

## What's Inside
Below is an overview of the core repository structure and the purpose of each directory:

*   `/.env` — Local environment variables and credential configurations.
*   `/config` — Database connection pools and infrastructure setup scripts.
*   `/docs` — Technical architecture diagrams and internal API references.
*   `/scripts` — Automation workflows, deployment helpers, and seeding routines.
*   `/src` — Core application logic and portal components.

## How to Use
Welcome to the team! Follow these quick steps to get the portal running locally on your machine:

1.  **Clone the Repository**: Pull the latest code down to your local environment.
2.  **Configure Environment Variables**: Ensure your local `.env` file matches the required credentials (API keys, database URLs, and AWS tokens).
3.  **Install Dependencies**: Initialize the project tools by running your language-specific package installation command (e.g., `npm install` or `pip install -r requirements.txt`).
4.  **Boot the Application**: Run the local boot script located in the scripts directory to launch your local testing instance.
